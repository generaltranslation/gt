Add deferred messages to `gt-i18n/unstable`. `msg` registers a message to translate later: `msg('Save')` returns the string unchanged, typed as the literal `'Save'`, and `` msg`Save` `` without values or options returns `'Save'`. A template with values or options (`` msg`Hello, ${{ name }}!` ``, `` msg({ context: 'button' })`Save` ``) returns a `Msg`: a plain object with the message tree, its hash and options, and the values as captured, so `date()`, `number()` and the other helpers work as in `t`. A `Msg` can be passed from a server component to a client component; React serializes its dates and bigints. `mFallback` renders messages untranslated for code without i18n. `gt-i18n/unstable/internal` adds `createMessages` and `getMessages`, which return an `m` (type `M`) that renders a `Msg` with its captured values, which per-call values override, through the same lookup as `t`. `m` checks a `Msg`'s shape, since it can come from props or storage, and throws for an object that is not one. A string, including legacy `msg()` output, is literal text with the same hash as `` t`...` `` of that text; ICU syntax such as `{`, `#` and `'` stays as written. `null` and `undefined` are returned unchanged.

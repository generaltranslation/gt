Make `paraglide-context` and `collectContext()` faster and lighter on memory, so that large projects finish: a run is about twice as fast on one core, a large project is analyzed on every core, and the syntax trees a run holds no longer grow with the project. `PARAGLIDE_CONTEXT_THREADS` sets the number of threads; `0` analyzes in the main thread. Metadata files are written in pieces, and only the lines around each usage are held: a project whose metadata is longer than the longest string Node holds no longer runs out of memory, and its metadata file can be read back. A barrel of many `export *` no longer makes a run quadratic, an outdir with one file per message is read at once, and Vue, Svelte and Astro components cost less. A Vue or VitePress file's generated code is no longer kept for the rest of the run. The metadata files are unchanged. Source files are now read at most 64 at a time. Before, on Node 24 and older, a project with more files than the process's open-file limit could leave usages out of the metadata files without a warning.

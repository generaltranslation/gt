Split every `number`, `date` and `time` option into message options, which a message tree holds, and formatting context, which it does not, so a tree converts to an ICU string and back without loss. The lists live in `@generaltranslation/icu/internal` (`NUMBER_MESSAGE_OPTIONS`, `NUMBER_CONTEXT_OPTIONS`, `DATE_MESSAGE_OPTIONS`, `TIME_MESSAGE_OPTIONS`, `DATE_FIELD_OPTIONS`, `TIME_FIELD_OPTIONS`, `DATE_TIME_CONTEXT_OPTIONS`), with types such as `NumberMessageOptions`, `NumberFormattingContext`, `DateMessageOptions`, `TimeMessageOptions`, `DateTimeFormattingContext` and `MessageTreeFormats` from the root entry.

- A number node's style is `'percent'`, `'currency'` or `{ style: 'unit', unit }` (printed `::unit/kilometer`); a date or time node's style is a named style (`'short'` to `'full'`) or date or time fields, printed as a skeleton whose hour is `j`, with `S` for `fractionalSecondDigits`, `B` for `dayPeriod`, and `z`, `O` or `v` for `timeZoneName`. `validateMessageTree` rejects formatting context, unknown options, a `dateStyle` or `timeStyle` written as an option, date fields on a time, an empty style `{}`, and field values Intl does not have.
- `buildMessageTree` returns `{ tree, values, formats }`: holes keep their full Intl options, the tree keeps the message options, and `formats` holds each variable's formatting context. A variable formatted with two different contexts in one message throws, and so does a `unit` without `style: 'unit'`. Holes add the `time` kind.
- `formatMessageTree(tree, locales, values, { formats, timeZone })` merges each variable's formats over its style, and `timeZone` is the default for a date or time whose formats set none. A `currency` style without a currency throws.
- Named date and time styles format as Intl's `dateStyle` and `timeStyle`, as in ICU, including through `formatMessage`, instead of intl-messageformat's field approximations. A date or time without a style, `{d, date}` or `{t, time}`, formats in the medium style, as ICU does. The ICU parser reads `S` as `fractionalSecondDigits`, `B` as `dayPeriod`, and `O`, `OOOO`, `v` and `vvvv` as `timeZoneName`; a `::unit/` skeleton keeps its whole unit, as in `::unit/kilometer-per-hour`, while `::measure-unit/` drops its category.
- `icuToMessageTree(icu)` takes no options and throws for a format a tree cannot hold, such as `{n, number, ::.00}` or more than three fractional second digits; every hour symbol reads as the hour. The new `checkTranslation(source, translation, { locale })` in `@generaltranslation/icu/convert` returns a message when a translation does not use the same variables, or the source's styles for them, and `undefined` otherwise. `IcuToMessageTreeOptions`, restoring formats from a source, and `findConflictingFormat` are removed.
- `formatMessageTree` and `formatMessage` resolve each locale once instead of on every call, and return a plain-text message without formatting it; rendering gt-cloud's own messages is about seven times faster.

Restyle the page `gt login` shows in the browser after the loopback callback to match the dashboard's auth screens: the hero's field behind a paper plate (inline as a data URI, no network request), the GT mark, a heading with a status glyph, and a note naming the signed-in account. A denied request and a failed exchange get their own pages, and both say to run `npx gt login` again.
